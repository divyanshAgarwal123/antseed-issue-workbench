# Walkthrough

[Watch or download the MP4](workbench-walkthrough.mp4) · [Transcript](transcript.txt)

The 46-second walkthrough explains the app using fresh browser captures from two successful runs on 2 November 2026: a synthetic export issue and a generated blue-rectangle image. The text run used GPT-OSS and Mistral models served by the same peer. The image run used Mimo and Mistral served by different peers. The app selected advertised zero-priced offers and pinned each request.

This video preserves the initial interface. The current app adds visible offer selection, structured result sections, streamed progress, review-only retries, JSON download and a labelled recorded example. See the main README screenshot and demo guide for the current controls.

The video uses cropped still captures with scene cuts and omits request waits. Captions make it understandable with sound off; narration uses the macOS Samantha speech voice. It ends with the repository's evidence guide. The model outputs are shown as returned and remain drafts for a human to verify.
